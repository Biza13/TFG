============================================================
  NOTAS IMPORTANTES
============================================================

- El backend en Render tarda ~30s en arrancar si lleva un rato sin tráfico
- Los archivos subidos directamente a Render SE BORRAN en cada redespliegue
  → Por eso se migra a Cloudinary
- Para hacer administrador a un usuario, ejecutar en la terminal de Clever Cloud:
  UPDATE user SET roles = '["ROLE_ADMIN","ROLE_USER"]' WHERE email = 'email@ejemplo.com';
- Para verificar manualmente un usuario:
  UPDATE user SET is_verified = 1 WHERE email = 'email@ejemplo.com';
- El comando de limpieza de eventos viejos se ejecuta manualmente:
  php bin/console app:clean-old-events
  (o añadir cron job en producción: 0 3 * * * php /ruta/bin/console app:clean-old-events)
